# Codex Project Workflow

## Quando Usar

Use esta skill para:

- criar documentos, mapas, planos e templates;
- organizar a pasta da SOU;
- atualizar arquivos de conhecimento;
- transformar conversas em processos reutilizáveis.

## Fluxo

1. Leia `AGENTS.md`.
2. Identifique se a tarefa é entrega única ou memória permanente.
3. Para entrega única, crie em `docs/` ou no caminho pedido.
4. Para conhecimento permanente, atualize `knowledge/`.
5. Para processo repetível, crie ou edite uma skill somente em `skills/`, a única raiz canônica da SOU.
6. Ao final, diga o que mudou e onde ficou.

## Convenções

- Use nomes claros em português quando o público for Fabio/SOU.
- Use Markdown para documentos.
- Evite arquivos enormes; quebre por tema quando fizer sentido.
- Não duplique memória: cada fato deve ter uma casa principal.
