# Seu Sócio de IA

Plugin do Codex para o aluno criar o próprio sistema de agentes por uma conversa guiada, no idioma em que ele falar.

## Uso

1. Instale o plugin no Codex.
2. Abra uma nova conversa, por texto ou pela voz nativa.
3. Diga: **"Quero montar meu Sócio de IA."**
4. Converse com o Arquiteto. Ele só cria arquivos após confirmar o plano com você.

O pacote não contém dados de nenhum aluno, empresa, criador ou negócio. Toda informação do sistema criado vem da conversa do próprio aluno.
